# 🎓 School Management System

A comprehensive, role-based School Management System built with PHP and MySQL.

## ✨ Features

### 🔐 Authentication & Authorization
- Secure login with password hashing (bcrypt)
- Role-based access control (Admin, HOD, Lecturer, Student)
- Session management
- User registration with email verification

### 👥 Admin Panel
- **User Management**: Add, edit, delete users
- **Department Management**: Create and manage departments
- **Course Management**: Create, edit, delete courses
- **Student Enrollment**: Enroll students in courses
- **System Analytics**: Dashboard with statistics

### 👔 HOD (Head of Department) Portal
- **Department Overview**: View department details
- **Course Management**: View all department courses
- **Lecturer Management**: View teaching staff
- **Approvals**: Pending approval requests
- **Reports**: Department performance analytics

### 👨‍🏫 Lecturer Portal
- **Dashboard**: Overview of teaching courses
- **Grade Management**: Enter and update student grades
- **Attendance System**: Take and manage class attendance
- **Course View**: View assigned courses

### 🎓 Student Portal
- **Dashboard**: View enrolled courses and performance
- **Course Listing**: View all enrolled courses with details
- **Grades**: View graded assignments and final grades
- **Attendance**: View attendance records

## 🛠️ Technology Stack

- **Backend**: PHP 7.4+
- **Database**: MySQL 5.7+
- **Frontend**: HTML5, CSS3, JavaScript
- **Security**: Password hashing, SQL injection prevention, XSS protection
